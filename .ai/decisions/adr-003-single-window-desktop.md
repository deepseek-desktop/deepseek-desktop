# ADR-003：单原生窗口桌面体验

## 状态

已采用。

## 决策

桌面管理界面与 Harness 工作台共用一个 Tauri 原生窗口，不为 Runtime 工作台另开浏览器或第二个应用窗口。启动、设置、诊断和关于通过桌面视图及原生菜单进入；Runtime ready 后在同一窗口加载受管 loopback Origin。

## 理由

- 避免两个窗口造成层级混乱、焦点切换和退出语义不一致。
- 让 Runtime 生命周期、窗口恢复和工作区状态由一个桌面宿主管理。
- 保留 Harness 原有工作台体验，同时隔离通用 Tauri 能力。

## 约束

- 只允许受管 Origin 进入工作台视图。
- 页面切换不能重复启动 Runtime，也不能在 ready 状态误开系统浏览器。
- 窗口位置和尺寸应按操作系统习惯恢复，并对失联显示器做可见区域兜底。
