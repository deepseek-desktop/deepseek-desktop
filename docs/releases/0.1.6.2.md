## 更新内容

### 新增

- 提供与本机 OpenCode 路由对齐的 [oMLX Qwen3.8 配置示例](https://github.com/deepseek-desktop/deepseek-desktop/blob/v0.1.6.2/docs/examples/omlx-qwen38.settings.yaml)：131072 上下文、32768 最大输出、Medium 默认推理、15 分钟流空闲超时与跨轮思考保留。示例使用当前 Harness 的真实配置 schema 校验。

### 修复

- 仓库命令超时回归改为确认整个进程组已回收，避免将登录 Shell 探测耗时计入固定两秒期限，减少高负载构建误报。

## 升级说明

退出应用后，选择上表中对应系统和架构的安装包进行更新。保留应用数据目录，继续使用原有模型配置、插件和会话。[安装与校验步骤](https://github.com/deepseek-desktop/deepseek-desktop/blob/HEAD/README.md#下载安装)。

Desktop 安装包与 Harness 独立更新是两条链路，仅更新 Harness 不会更新桌面外壳。DSH Market 在本版中仍需按官方 CLI 方式安装；随 Harness 自动同步市场是后续主分支功能，不在本版安装包内。
