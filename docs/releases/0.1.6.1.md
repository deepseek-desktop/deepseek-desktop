## 更新内容

- 默认内核仓库切换为 `deepseek-desktop/deepseek-harness`，继续使用已审计的同一提交，来源身份改变而内核字节不变。
- 公开版本统一为四段数字：前三段对应 Harness 版本，第四段是 Desktop 修订号。Tag、窗口、更新提示、发布目录和安装包名称保持一致。
- 标准 `pnpm install`、`pnpm run build` 完成完整桌面构建流程；验证与 E2E 在使用 Harness 前按当前 lock 准备依赖，避免复用损坏或不完整的生成目录。

## 升级说明

退出应用后，选择上表中对应系统和架构的安装包进行更新。保留应用数据目录，继续使用原有模型配置、插件和会话。[安装与校验步骤](https://github.com/deepseek-desktop/deepseek-desktop/blob/HEAD/README.md#下载安装)。

Desktop 安装包与 Harness 独立更新是两条链路，仅更新 Harness 不会更新桌面外壳。DSH Market 在本版中仍需按官方 CLI 方式安装；随 Harness 自动同步市场是后续主分支功能，不在本版安装包内。

## 验证与限制

本页变更与内核信息依据 [对应 Tag 源码](https://github.com/deepseek-desktop/deepseek-desktop/tree/v0.1.6.1)整理。未在此记录本版公开下载包的独立实机验收，不使用后续版本的模型测试结果代替。需要已记录的下载校验和本机模型验收，请查看 [v0.1.6.2](https://github.com/deepseek-desktop/deepseek-desktop/releases/tag/v0.1.6.2)。

- macOS 有 ad-hoc 完整性签名，尚无 Apple Developer ID 签名和公证；Windows 尚无 Authenticode 签名，Linux 安装包未提供可信发布者签名。
- 本版为社区预发布，不占据 Latest。Desktop 仅提供新版提醒与手动下载入口；Harness 使用独立的更新验证流程。
